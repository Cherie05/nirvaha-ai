---------------------------------------------------------------------
SIGNUP IS DISABLED
---------------------------------------------------------------------

POST /api/auth/register returns 403 "Signup is disabled for this demo."

Use the accounts above.


---------------------------------------------------------------------
CHANGING THEM
---------------------------------------------------------------------

All values live in src/backend/.env :

  DEMO_EMAIL=test@gmail.com
  DEMO_PASSWORD=test@1234
  DEMO_OTP=123456
  ALLOW_REGISTRATION=false

The seeder re-syncs the password hash on every boot, so editing
DEMO_PASSWORD and restarting is enough — no manual database work.

  docker compose up -d -V api
